# SOC Investigation Case Studies

A public portfolio of sanitized SOC investigation reports covering WAF, VPN, Web Proxy, Firewall, and IPS security events.

> **Public-portfolio note:** These reports have been sanitized to remove internal/private IP addresses, employee identities, internal hostnames, organization-specific domains, and internal contact information. Public threat-intelligence indicators may remain where they are useful to demonstrate investigation methodology.

## Coverage

| Security Technology | Cases | Investigation Focus |
|---|---:|---|
| WAF | 5 | Web application attacks and abuse |
| VPN | 5 | Authentication and remote-access anomalies |
| Web Proxy | 5 | Suspicious browsing, downloads and data transfer |
| Firewall | 3 | Network attacks and reconnaissance |
| IPS | 2 | Network intrusion and exploitation attempts |
| **Total** | **20** | |

## Investigation Workflow

1. Alert and ticket review
2. Initial triage
3. Source/destination analysis
4. Log investigation and correlation
5. IOC and reputation analysis
6. Timeline reconstruction
7. Impact assessment
8. Incident classification
9. Containment/remediation
10. Recommendations and closure

## Tools and Techniques

- Splunk log analysis and queries
- WAF, VPN, proxy, firewall and IPS telemetry
- Threat-intelligence/reputation checks
- IOC scoping and event correlation
- Endpoint/DLP investigation where applicable
- Incident response and remediation documentation
